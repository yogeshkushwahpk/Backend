# Template Engines and EJS

## Academic sessions 17 and 18: Render HTML from Express

---

## 1. Why use a template engine?

An API usually returns JSON. A server-rendered website returns HTML. A template engine lets Express create HTML from a template plus data, instead of building long HTML strings in every route.

EJS means Embedded JavaScript. It is a simple template engine for Express.

## 2. Install and configure EJS

```bash
npm install ejs
```

Create this structure:

```text
project/
  app.js
  views/
    home.ejs
```

Configure Express:

```js
const express = require('express');
const app = express();

app.set('view engine', 'ejs');

app.get('/', (req, res) => {
  res.render('home', { title: 'Backend Course', studentName: 'Student' });
});

app.listen(3000);
```

Create `views/home.ejs`:

```html
<!doctype html>
<html lang="en">
  <head><title><%= title %></title></head>
  <body>
    <h1>Welcome, <%= studentName %>!</h1>
  </body>
</html>
```

`<%= value %>` escapes HTML and is the safe default for displaying text. Do not use unescaped output for untrusted user input.

## 3. When to use templates versus JSON

| Need | Better response |
| --- | --- |
| Browser page rendered by the server | `res.render()` with EJS |
| React/mobile/another frontend consumes the backend | `res.json()` |
| Download or plain text response | `res.send()` or a file response |
