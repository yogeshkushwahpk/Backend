# Project: Middleware Logger and CORS Server

## Academic session 9: Apply middleware in one small API

Complete the middleware and practical CORS lessons before this project.

## Goal

Build a small JSON API that logs every request and accepts browser requests from one approved frontend origin.

## Setup

```bash
npm install express cors
```

```js
const express = require('express');
const cors = require('cors');

const app = express();
const port = 3000;

function requestLogger(req, res, next) {
  console.log(`${new Date().toISOString()} ${req.method} ${req.originalUrl}`);
  next();
}

app.use(requestLogger);
app.use(express.json());
app.use(
  cors({
    origin: 'http://localhost:5173',
    methods: ['GET', 'POST'],
  })
);

const messages = [];

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});

app.post('/api/messages', (req, res) => {
  const { text } = req.body;

  if (!text || !text.trim()) {
    return res.status(400).json({ message: 'text is required' });
  }

  const message = { id: messages.length + 1, text: text.trim() };
  messages.push(message);
  return res.status(201).json(message);
});

app.listen(port, () => console.log(`API running on port ${port}`));
```

## Check your work

1. Call `GET /api/health`; confirm one log line appears.
2. Send valid and invalid JSON requests to `POST /api/messages`.
3. Call the API from an approved frontend origin.
4. Change the origin temporarily and observe the browser CORS error.

Keep the logger before routes. A middleware registered after a route cannot log a request that the route has already completed.
