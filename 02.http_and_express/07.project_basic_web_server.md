# Project: Basic Express Web Server

## Academic sessions 3–5: Server, request/response, and simple routes

Build this project after `00.express_start_here` and `01.express_introduction`.

## Goal

Create a small website server with three routes and a useful 404 response. Do not use a database, authentication, middleware, or templates yet.

## Requirements

- `GET /` returns a welcome message.
- `GET /about` returns a short course description.
- `GET /contact` returns contact information.
- Any other route returns `404` with a clear message.

```js
const express = require('express');

const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('<h1>Welcome to my Express server</h1>');
});

app.get('/about', (req, res) => {
  res.send('This site is built with Express.');
});

app.get('/contact', (req, res) => {
  res.json({ email: 'hello@example.com' });
});

app.use((req, res) => {
  res.status(404).send('Page not found');
});

app.listen(port, () => {
  console.log(`Open http://localhost:${port}`);
});
```

## Test checklist

Open `/`, `/about`, `/contact`, and `/does-not-exist` in a browser. For every route, identify the request method, path, status code, and response body.
