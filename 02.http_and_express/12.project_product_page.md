# Project: Dynamic Product Page with EJS

## Academic session 20: Build a server-rendered product listing

## Goal

Build `/products` and `/products/:id` pages with EJS. Use in-memory data first so that the focus stays on views and routes.

```js
const products = [
  { id: 1, name: 'Notebook', price: 99, category: 'Stationery' },
  { id: 2, name: 'Desk Lamp', price: 799, category: 'Home' },
];

app.get('/products', (req, res) => {
  res.render('products', { title: 'Products', products });
});

app.get('/products/:id', (req, res) => {
  const id = Number(req.params.id);
  const product = products.find((item) => item.id === id);

  if (!product) {
    return res.status(404).render('not-found', { title: 'Product not found' });
  }

  return res.render('product-detail', { title: product.name, product });
});
```

## Requirements

- A listing page with product name, price, category, and a detail link.
- A product-detail page with all product information.
- A 404 EJS page for invalid or missing ids.
- At least one shared layout element, such as a header or footer partial.
- A README with screenshots or URLs for the listing and detail pages.

After the database module, rebuild this project with a Mongoose Product model instead of the in-memory array.
