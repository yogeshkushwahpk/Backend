# Dynamic EJS Rendering: Project Blog Viewer

## Academic sessions 16 and 19: Dynamic routes and dynamic views

Complete the route-parameter lesson in `04.advanced_api_engineering/01.route_parameters.md` before this project.

## Goal

Render a list of blog posts and a detail page selected by a dynamic route parameter.

```js
const posts = [
  { slug: 'learn-node', title: 'Learn Node.js', body: 'Node runs JavaScript on the server.' },
  { slug: 'learn-express', title: 'Learn Express', body: 'Express makes routes easier.' },
];

app.get('/posts', (req, res) => {
  res.render('posts', { title: 'Blog posts', posts });
});

app.get('/posts/:slug', (req, res) => {
  const post = posts.find((item) => item.slug === req.params.slug);

  if (!post) {
    return res.status(404).render('not-found', { title: 'Post not found' });
  }

  return res.render('post-detail', { title: post.title, post });
});
```

`views/posts.ejs`:

```html
<h1><%= title %></h1>
<ul>
  <% posts.forEach((post) => { %>
    <li><a href="/posts/<%= post.slug %>"><%= post.title %></a></li>
  <% }) %>
</ul>
```

`views/post-detail.ejs`:

```html
<h1><%= post.title %></h1>
<p><%= post.body %></p>
<a href="/posts">Back to posts</a>
```

## Requirements

- Use a meaningful slug such as `learn-node`, not an array index.
- Render a custom 404 page for an unknown slug.
- Keep the post data separate from route code.
- Add one more post and confirm the list updates automatically.

This is a view project. The database version of this project comes after the MongoDB module.
