## 1. Read HTML form data

Browsers commonly submit a form as `application/x-www-form-urlencoded`. Add the built-in parser before routes that need `req.body`.

```js
const express = require('express');
const app = express();

app.use(express.urlencoded({ extended: true }));
app.use(express.json());
```

`express.urlencoded()` handles regular HTML forms. `express.json()` handles JSON clients such as `fetch`, Postman, and a React application.

## 2. GET form example

This route receives a search query from a URL such as `/search?term=node`.

```js
app.get('/search', (req, res) => {
  const term = (req.query.term || '').trim();
  res.send(`You searched for: ${term || 'nothing'}`);
});
```

## 3. Contact Form API

```js
const contacts = [];

app.post('/contact', (req, res) => {
  const { name, email, message } = req.body;

  if (!name?.trim() || !email?.trim() || !message?.trim()) {
    return res.status(400).json({
      message: 'name, email, and message are required',
    });
  }

  const contact = {
    id: contacts.length + 1,
    name: name.trim(),
    email: email.trim().toLowerCase(),
    message: message.trim(),
    createdAt: new Date().toISOString(),
  };

  contacts.push(contact);
  return res.status(201).json({ message: 'Thank you for contacting us', contact });
});

app.get('/contact', (req, res) => {
  res.json(contacts);
});
```

## 4. Test with a real HTML form

```html
<form action="http://localhost:3000/contact" method="POST">
  <input name="name" placeholder="Your name" required />
  <input name="email" type="email" placeholder="you@example.com" required />
  <textarea name="message" required></textarea>
  <button type="submit">Send</button>
</form>
```

The browser sends this form as URL-encoded data. Check `req.body` once with `console.log`, then remove the temporary log.

## Project requirements

- Add a `GET /contact` route that returns all received contacts.
- Reject a missing field with status `400`.
- Return status `201` after a valid submission.
- Test one form submission in a browser and one JSON submission in Postman or Thunder Client.

This project intentionally stores data in memory. Database storage comes later in the MongoDB module.
