# Serving Static Files with Express

## Academic session 29: CSS, browser JavaScript, and images

---

Put files that Express should send unchanged into a `public` folder.

```text
project/
  app.js
  public/
    css/style.css
    js/site.js
    images/logo.png
  views/
    home.ejs
```

Register the folder before your routes:

```js
const path = require('path');

app.use(express.static(path.join(__dirname, 'public')));
```

Now the browser can request:

```text
/css/style.css
/js/site.js
/images/logo.png
```

In an EJS view, use an absolute public URL:

```html
<link rel="stylesheet" href="/css/style.css" />
<script defer src="/js/site.js"></script>
```

## Practice

Add CSS to the Product Page project. Confirm that opening `/css/style.css` directly in the browser returns the stylesheet. Never put secret files, `.env`, source files, or `node_modules` inside `public`.
