# Start Express Without Confusion

## Your First Framework-Based Backend Application

---

## Before you begin

Finish `01.node_fundamentals` first. You should be comfortable with these ideas:

- Node.js runs JavaScript outside the browser.
- `npm` installs a package and `package.json` records it.
- `require()` loads a module.
- An HTTP server receives a request and sends a response.
- `async`/`await` and `try`/`catch` will be used later.

You do **not** need a database, MongoDB, authentication, middleware theory, REST rules, or CORS before this module.

## What Express is

Express is a Node.js package that makes it easier to create web servers and API routes. It still uses Node and HTTP underneath.

| Node.js | Express |
| --- | --- |
| Runtime that runs your backend JavaScript | Framework installed inside a Node project |
| Can create a raw HTTP server | Makes routes and responses easier to write |
| Required first | Used after Node fundamentals |

## Build the smallest Express server

Create a new folder and run these commands in its terminal:

```bash
npm init -y
npm install express
```

Create `index.js`:

```js
const express = require('express');

const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.json({ message: 'My first Express server works!' });
});

app.listen(port, () => {
  console.log(`Server running at http://localhost:${port}`);
});
```

Start it:

```bash
node index.js
```

Open `http://localhost:3000` in a browser. You should see JSON with the message. Stop the server with `Ctrl + C`.

## What each important line means

| Code | Meaning |
| --- | --- |
| `require('express')` | Loads the installed Express package. |
| `express()` | Creates your application object. |
| `app.get('/')` | Runs this function for a `GET` request to `/`. |
| `req` | Information sent by the client. |
| `res` | The object used to send a response. |
| `res.json(...)` | Sends JSON and sets the correct response header. |
| `app.listen(...)` | Starts the server on a port. |

## If it does not work

- **`Cannot find module 'express'`:** run `npm install express` in the same folder as `index.js`.
- **`EADDRINUSE`:** port 3000 is already in use; stop the other server or change `port`.
- **Browser cannot connect:** confirm `node index.js` is still running and use the exact URL printed in the terminal.
- **`require is not defined`:** this course starts with CommonJS. Do not add `"type": "module"` to `package.json` yet.

When this small server works, continue to lesson 01. Do not skip straight to middleware, authentication, or databases.
