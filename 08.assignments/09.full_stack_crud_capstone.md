# Final Project: Full-Stack CRUD Application

## Academic session 37, using session 36 frontend integration

## Choose one product

Build a Task Manager, Blog Manager, Book Tracker, or Student Directory. The application needs an Express backend, MongoDB database, and a usable frontend.

## Minimum backend requirements

- Express application with MVC folders.
- MongoDB and Mongoose model.
- Create, list, read-one, update, and delete endpoints.
- Correct HTTP methods and status codes.
- Request validation and helpful error responses.
- Pagination or filtering for the list endpoint.
- Postman collection or Thunder Client collection documenting every endpoint.

Example task routes:

```text
POST   /api/tasks
GET    /api/tasks
GET    /api/tasks/:id
PATCH  /api/tasks/:id
DELETE /api/tasks/:id
```

## Minimum frontend requirements

- A list page that fetches and displays records.
- A form that creates a record.
- Edit and delete actions.
- Loading, empty, and error states.
- A visible success or failure message after a write.

You may use EJS for a same-origin server-rendered frontend, or HTML/JavaScript/React for a separate frontend. If the frontend runs on a different origin, configure CORS using the course CORS lesson.

## Suggested milestones

1. Design the model and sketch the screens.
2. Build and test backend CRUD routes with Postman.
3. Connect MongoDB and add validation.
4. Build the frontend list and create form.
5. Add edit and delete operations.
6. Test error cases, then deploy or record a demo.

## Submission checklist

- GitHub repository with clear setup instructions.
- `.env.example`, never a real `.env` file.
- API documentation collection.
- Screenshots or a short demo video.
- Explanation of model design and validation rules.
- Proof that create, read, update, and delete all work from the frontend.

Authentication, rate limiting, uploads, search, and deployment are valuable extensions, but are not required for the academic capstone baseline.
